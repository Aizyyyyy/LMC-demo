# Les Maisons Club — concept prototype

A self-contained interactive web demo for presenting Ani’s independent LMC concept. It demonstrates Maison-by-Maison preferences and updates the sample discovery feed when a switch changes.

## Run it

Open `index.html` in any modern browser. No installation, server, API key or network connection is needed. The example recommendations are static; the page does not use AI, a backend or customer data. Preference selections are not saved when the page closes.

## Publish it

For a shareable URL, upload the `lmc-demo` folder to any static website host. Two straightforward options are:

- **GitHub Pages:** put the folder contents in a repository, enable Pages for the chosen branch and folder, then copy the published URL.
- **Netlify Drop:** drag the `lmc-demo` folder into Netlify’s manual deploy page and use the URL it provides.

The site consists of one HTML file. Keep `index.html` at the published site’s root. A host may ask you to sign in or create an account.

## Link it from a PPTX

1. Publish the page and copy its public URL.
2. In PowerPoint, select the text, shape or image to act as the link.
3. Choose **Insert → Link** (or press **Ctrl+K**), paste the URL, and confirm.
4. Use a clear label such as **Open the LMC interactive concept**. During the presentation, open the link from Slide Show mode; test the link on the presentation computer beforehand.

## Concept and disclosure

The page labels itself as an independent concept prototype, not an official LVMH or Maison product. Maison names are illustrative examples only and do not imply endorsement, participation or affiliation. The sample content is fictional and static. The interface expresses the concept principles supplied for this demo: one discovery experience, customer-selected Maisons, recommendations limited to selected Maisons, clear consent, and respect for Maison autonomy.
